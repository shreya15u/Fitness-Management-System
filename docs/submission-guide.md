# Submission Guide

## Project Name
Online Fitness Platform

## Student-Friendly Submission Items
- Source code
- Database script
- Project synopsis
- Full project report
- Architecture and flow explanation
- Viva questions

## Files to Submit
- `src/`
- `database/schema.sql`
- `README.md`
- `docs/project-synopsis.md`
- `docs/project-report.md`
- `docs/architecture-and-flow.md`
- `docs/viva-questions.md`

## How to Demonstrate
1. Run the MySQL script from `database/schema.sql`
2. Update the database username and password in `DatabaseConnection.java`
3. Compile the Java code
4. Start the application
5. Demonstrate:
   Register user
   Login user
   Add workout
   View workout
   Update workout
   Delete workout
   Update profile
   View progress summary

## Short Presentation Flow
1. Introduce the problem
2. Explain the objective
3. Describe the technologies used
4. Show the database design
5. Explain OOP implementation
6. Show the application flow
7. Discuss challenges and solutions
8. End with future scope
