# Demo Script

## Demo Order
1. Open the project and explain the project title
2. Show the database schema
3. Run the application
4. Register a new user
5. Log in with that user
6. Add workout details
7. View workout history
8. Update one workout record
9. Delete one workout record
10. Update profile details
11. Show progress summary
12. Explain OOP concepts used
13. End with future scope

## What to Say During Demo

### Introduction
This is my Online Fitness Platform project developed using Java and MySQL. It is designed to help users manage workouts digitally with secure authentication and progress tracking.

### Registration
Here I am registering a new user by entering name, email, password, age, and fitness goal. The data is stored in the users table.

### Login
Now I am logging in with the registered credentials. The system checks the entered details with the database.

### Add Workout
After login, the user enters the dashboard. Here I can add workout name, duration, calories burned, and date.

### View Workout
This option displays all workouts saved for the currently logged-in user.

### Update and Delete Workout
I can also update existing workout details or delete a record if it is no longer needed.

### Profile
The profile section displays personal information and allows updates.

### Progress Summary
This section calculates the total workouts, total training minutes, and total calories burned.

### OOP
This project uses encapsulation, inheritance, abstraction, and polymorphism to keep the system modular and easy to maintain.

### Conclusion
This project solves the issue of manual workout tracking by providing a simple and structured digital system.
